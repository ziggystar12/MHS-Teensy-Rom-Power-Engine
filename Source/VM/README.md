# VM source

The firmware handles hardware services. Doom is loaded separately from SD.

| Folder | Contents |
| --- | --- |
| abi | Module format and host interface |
| client | C64 input, display and sound client |
| video | Shared C64 video conversion |
| doom | Doom engine adapters |
| tests | Host and C64 client tests |

Download packages live in [vms](../../vms/), not in this source tree.
