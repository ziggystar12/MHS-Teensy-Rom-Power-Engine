# NUFLIX display support

Scheduler, packer and display-template adaptations from NUFLIX Studio by
Patai Gergely: https://github.com/cobbpg/nuflix-studio

Based on commit b33f4d93875a3fdbabaf52216811962847fdfcf1.
MHS adaptations add bounded incremental fitting, inactive-bank uploads and
shared-host scheduling. Generated display data is included as C++ headers.
